### 0.4 执行约定（**所有任务都遵守**）

1. **TDD 节奏**：写测试 → 跑测试看到失败 → 实现 → 跑测试看到通过 → commit
2. **提交格式**：`<type>(<scope>): <description>`
   - `type` ∈ {feat, fix, refactor, test, docs, chore, style}
   - `scope` 是模块名：`auth`, `user`, `credit`, `payment`, `ai`, `generate`, `admin`, `shared`, `web`, `server`, `webapp`...
   - 例：`feat(auth): 短信验证码登录 + JWT`、`fix(ai): 主模型 5xx 退积分时漏写 audit_log`
3. **绝对路径**：所有文件操作都用 `/Users/chenjin/Downloads/beautify_work/...` 绝对路径
4. **分支**：`feature/h5-redesign`（当前活跃分支）
5. **测试命令**：
   - 单元：`npm run test:unit`
   - 集成：`npm run test:integration`（需本地 Docker PG/Redis）
   - E2E：`npm run test:e2e`（需 Playwright + 本地 dev server）
   - 全部：`npm test`
6. **代码组织**：
   - 单文件单一职责
   - 业务/控制器/服务/仓储分离（NestJS 模块化）
   - 共享代码放 `server/src/common/` 或 `shared/`
7. **deferred 标记**：任务中标 **(deferred)** 的步骤需真实环境（阿里云账号 / 微信商户号 / 真实手机号 / 真实 OSS / 真实域名），本地不执行，标记 ⏸ pending-deployment
8. **环境变量**：所有 secret 走 `process.env`，在 `server/src/config/` 集中加载，配 `.env.example` 模板。**不提交真实值到 git**。

```typescript
    if (!required || required.length === 0) return true;
    const { user } = context.switchToHttp().getRequest();
    if (!user || !required.includes(user.role)) {
      throw new ForbiddenException('权限不足');
    }
    return true;
  }
}
```

`http-exception.filter.ts`：
```typescript
import { ExceptionFilter, Catch, ArgumentsHost, HttpException, HttpStatus, Logger } from '@nestjs/common';
import { Request, Response } from 'express';

@Catch()
export class HttpExceptionFilter implements ExceptionFilter {
  private readonly logger = new Logger(HttpExceptionFilter.name);

  catch(exception: unknown, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const res = ctx.getResponse<Response>();
    const req = ctx.getRequest<Request>();

    let status = HttpStatus.INTERNAL_SERVER_ERROR;
    let message: string | object = 'Internal Server Error';
    let code = 500;

    if (exception instanceof HttpException) {
      status = exception.getStatus();
      const r = exception.getResponse();
      if (typeof r === 'string') { message = r; }
      else if (typeof r === 'object' && r !== null) {
        message = (r as any).message ?? r;
        code = (r as any).code ?? status;
      }
    } else if (exception instanceof Error) {
      message = exception.message;
      this.logger.error(exception.stack);
    }

    res.status(status).json({ code, message, data: null, path: req.url, timestamp: new Date().toISOString() });
  }
}
```

## 3. 卡壳怎么办？

| 症状 | 排查 |
|---|---|
| `docker compose up -d` 失败 | Docker Desktop 未启 / 5432/6379 端口被占 → `lsof -i :5432` / `lsof -i :6379` |
| `npm install` 失败 | Node 版本（需 20+，用 `nvm use`） / 网络（用 pnpm 更快）|
| `npm run test:unit` 失败 | 看 traceback；先确认测试是不是已 import 实际代码 |
| `migration:run` 失败 | 检查 `dataSource` 配置 / `entities` 路径 / DB 是否启动 |
| TypeORM 找不到实体 | 检查 `entities: [__dirname + '/**/*.entity{.ts,.js}']` glob 模式 |
| 短信发送失败 | 阿里云 AccessKey / 签名 / 模板号 / 余额 |
| 支付回调收不到 | 回调 URL 必须公网可达（开发用 ngrok/钉钉内网穿透）|
| AI 调用失败 | API key / 配额 / 临时签名 URL 过期（OSS 签名默认 30 min）|
| Bull 队列堆积 | Redis 内存 / Worker 进程是否在跑 / 任务失败被 retry |
| Token 失效 | access 过期调 /api/auth/refresh；refresh 过期重新登录 |
| DB 写入失败 | 配额 / 字段类型不匹配 / 唯一索引冲突 |
| 前端响应式错位 | 检查 `<768px` 断点；Vant 组件默认就是移动端，PC 端用 Element Plus |
| 跨域问题 | NestJS 配 `app.enableCors({ origin: [FRONTEND_URL, ADMIN_URL] })` |
| Docker 镜像太大 | 多阶段构建；server 用 `node:20-alpine`；sharp 用官方镜像 |
