### 0.4 执行约定（**所有任务都遵守**）

1. **TDD 节奏**：写测试 → 跑测试看到失败 → 实现 → 跑测试看到通过 → commit
2. **提交格式**：`<type>(<scope>): <description>`
   - `type` ∈ {feat, fix, refactor, test, docs, chore, style}
   - `scope` 是模块名（user, generate, ai, admin, shared, ...）
   - 例：`feat(user): login 云函数`、`fix(ai): 主模型 5xx 退积分时漏写 audit_log`
3. **绝对路径**：所有文件操作都用 `/home/ubuntu/personal_work/...` 绝对路径
4. **分支**：`main`（本仓是绿仓，无 main 保护；不需要 PR 流程）
5. **测试命令**：
   - 单元测试：`npm run test:unit`
   - 集成测试：`npm run test:integration`（需要云开发环境）
   - 全部：`npm test`
6. **代码组织**：
   - 每个文件单一职责
   - 业务/模型/路由分离（小程序端）
   - 服务/工具/中间件分离（云函数端）
7. **deferred 标记**：任务中标 **(deferred)** 的步骤需要真实环境（云开发账号 / 商户号 / AI key / 微信开发者工具 CLI），本地不执行，标记 ⏸ pending-deployment

```javascript
const fs = require('fs').promises;
const path = require('path');

const STATE_COLL = '_migrations';

async function list() {
  const files = await fs.readdir(__dirname);
  return files.filter(f => /^\d+_.*\.js$/.test(f)).sort();
}

async function run(db) {
  const migrations = await list();
  const state = await db.collection(STATE_COLL).get();
  const applied = new Set(state.data.map(s => s.name));
  for (const name of migrations) {
    if (applied.has(name)) continue;
    const m = require(path.join(__dirname, name));
    if (typeof m.up !== 'function') {
      throw new Error(`Migration ${name} missing up()`);
    }
    await m.up(db);
    await db.collection(STATE_COLL).add({ name, applied_at: new Date() });
    console.log(`[migration] applied ${name}`);
  }
}

module.exports = { list, run };
```

## 3. 卡壳怎么办？

| 症状 | 排查 |
|---|---|
| `npm install` 失败 | 检查 node 版本（需 18+）和 npm 版本 |
| 单元测试失败 | 看 traceback；先确认测试是不是已 import 实际代码 |
| 云函数部署失败 | 检查 `cloudfunctions/<fn>/package.json` 的 `wx-server-sdk` 版本 |
| 提示词效果差 | 调整 `preset_items.default_prompt` 字段（运营后台可改） |
| AI 角标不显示 | 确认 worker 的 `sharp` 库装好 |
| 微信支付回调收不到 | 检查商户平台回调 URL 配置 + 云函数 HTTP 触发器 |
| 订阅消息发不出 | 模板 ID 错误 / 用户没授权（一次性订阅） |
| Token 失效 | 用户重新登录即可；检查 JWT_SECRET 是否变更 |
| 数据库写入失败 | 检查是否超配额 / 字段类型不匹配 |
