## 一、背景与目标

项目 AI 模块已有完整的适配器架构（AiAdapter 接口 + AIService 路由），但 TongyiAdapter 的 `editImage()` 只有 mock 路径，生产路径是 503 stub。本次目标是接入通义万相 `wanx2.1-img2img` 真实 API，实现本地可调试的图片编辑链路。

## 二、模型调研结论

### 大模型图片编辑 API 对比

| 厂商 | 模型 | 单价 | 特点 |
|---|---|---|---|
| **阿里通义万相** | wanx2.1-img2img | 0.04元/次 | 最便宜，文档最全，已有 adapter 桩，与 OSS 同生态 |
| 阿里通义万相 | wanx-local-inpainting | 0.04元/次 | 局部重绘（需 mask），v2 再考虑 |
| 腾讯混元 | 图生图 | 0.04元/次 | 局部重绘 0.06元，501 桩暂不动 |
| 字节即梦 | img2img | ~0.04元/次 | 人脸生成质量好，可后续新增 adapter |
| 百度千帆 | img2img | 0.04-0.10元/次 | 性价比低，不推荐 |

### 传统 CV 人脸美型 API

| 厂商 | 单价 | 特点 |
|---|---|---|
| 腾讯云人脸美型 | 0.002-0.01元/次 | 延迟<1秒，但只能做几何形变 |
| 美图开放平台 | 中等 | 效果最好，但仍是几何形变 |
| 百度AI人脸美型 | 0.002-0.005元/次 | 最便宜 |

### 为什么不用传统 CV？

**隆鼻、垫下巴是"加法"操作**（生成原本没有的组织），CV 关键点形变只能做"减法"（拉伸/缩放现有像素），效果机械，无法胜任医美预览场景。如果未来需要"瘦脸"等纯形变项目，可新增 CV 适配器作为 fast path。

### 最终选择

**通义万相 `wanx2.1-img2img`**：0.04 元/次，项目已有 adapter 桩，阿里云生态与 OSS 一致，接入成本最低。

## 三、DashScope API 技术方案

### 异步调用流程

DashScope 的图生图 API 是**异步模式**，调用分两步：

**Step 1 — 提交任务**
```
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/image2image/image-synthesis
Headers:
  Authorization: Bearer <TONGYI_API_KEY>
  Content-Type: application/json
  X-DashScope-Async: enable

Body:
{
  "model": "wanx2.1-img2img",
  "input": {
    "image_url": "<imageSignedUrl>",
    "prompt": "<composed prompt>"
  },
  "parameters": {
    "n": 1,
    "size": "1024*1024",
    "strength": 0.55
  }
}

Response (202):
{
  "output": { "task_id": "xxx-xxx", "task_status": "PENDING" },
  "request_id": "yyy"
}
```

**Step 2 — 轮询任务结果**
```
GET https://dashscope.aliyuncs.com/api/v1/tasks/{task_id}
Headers:
  Authorization: Bearer <TONGYI_API_KEY>

Response (200, SUCCEEDED):
{
  "output": {
    "task_id": "xxx",
    "task_status": "SUCCEEDED",
    "results": [{ "url": "https://dashscope-result-xxx.oss-cn-beijing.aliyuncs.com/result.png" }]
  }
}
```

**Step 3 — 下载结果图片**：GET 结果 URL 得到 arraybuffer，转 Buffer 返回。

### 关键参数

| 参数 | 值 | 理由 |
|---|---|---|
| `model` | `wanx2.1-img2img` | 当前最新图生图模型 |
| `parameters.n` | `1` | 医美预览只需一张 |
| `parameters.size` | `1024*1024` | 与现有 watermark pipeline 一致 |
| `parameters.strength` | `0.55` | 0-1 之间，0.55 保持面部特征同时有明显变化 |

## 四、改造清单

### Step 1：安装依赖

```bash
cd server && npm install @nestjs/axios
```

`@nestjs/axios` 提供 `HttpService`（基于 axios），与 NestJS DI 集成，方便 mock 测试。

### Step 2：改造 TongyiAdapter（核心）

**文件**: `server/src/ai/adapters/tongyi.adapter.ts`

**关键改动**：

1. **判断条件从 `NODE_ENV` 改为 `API Key 是否存在`**
   - 有 key → 走真实 DashScope 调用
   - 无 key → 走现有 mock 合成路径（确保 CI 和本地无 key 开发不受影响）

2. **新增 DashScope 异步调用逻辑**：
   - 提交任务：`POST /api/v1/services/aigc/image2image/image-synthesis`
   - 轮询结果：`GET /api/v1/tasks/{task_id}`（2s 间隔，最多 30 次 = 60s）
   - 下载结果图片 URL → Buffer

3. **常量定义**：
   ```typescript
   private static readonly MODEL_ID = 'wanx2.1-img2img';
   private static readonly COST_CENTS = 4;        // 0.04元 = 4分
   private static readonly BASE_URL = 'https://dashscope.aliyuncs.com/api/v1';
   private static readonly POLL_INTERVAL_MS = 2000;
   private static readonly POLL_MAX_ATTEMPTS = 30;  // 最多等60秒
   private static readonly DEFAULT_STRENGTH = 0.55;
   ```

4. **错误映射**：
   | DashScope 响应 | 映射异常 | AIService 行为 |
   |---|---|---|
   | 4xx（InvalidAPIKey/InvalidParameter） | BadRequestException (400) | 不重试 |
   | 5xx / 网络超时 | BadGatewayException (502) | 重试 |
   | 任务 FAILED | BadGatewayException (502) | 重试 |
   | 轮询超时 | GatewayTimeoutException (504) | 重试 |

5. **editImage 伪代码**：
   ```typescript
   async editImage(input: AiEditInput): Promise<AiEditResult> {
     const start = Date.now();
     const apiKey = this.cfg.get<string>('TONGYI_API_KEY');

     // 无 Key → 走本地合成（不烧配额，不影响 CI）
     if (!apiKey) {
       return this.synthesizePlaceholder(start);
     }

     // 有 Key → 真实调用
     const taskId = await this.submitTask(apiKey, input);
     const resultUrl = await this.pollUntilDone(apiKey, taskId);
     const resultBuffer = await this.downloadResult(resultUrl);

     return {
       resultBuffer,
       modelUsed: TongyiAdapter.MODEL_ID,
       costCents: TongyiAdapter.COST_CENTS,
       latencyMs: Date.now() - start,
     };
   }
   ```

## 七、注意事项

| 事项 | 说明 |
|---|---|
| **签名 URL 可达性** | DashScope 服务器需访问 `imageSignedUrl`，本地必须配 OSS AK/SK 使 URL 指向公网 OSS，不能走 localhost 的 dev-file endpoint |
| **DashScope QPS 限制** | 默认 2 QPS，Worker concurrency=4 可能触发 429，AIService 的 retry 会兜底 |
| **CI 环境** | `TONGYI_API_KEY` 不进 CI 环境变量，确保 CI 走 mock 路径 |
| **结果 URL 有效期** | 1 小时，但 GenerateProcessor 获取 buffer 后立即上传 OSS，无过期风险 |
| **成本** | 0.04 元/次 = 4 分/次，本地测试 10 次不到 0.5 元 |

## 八、后续扩展方向（v2）

1. **新增 `wanx-local-inpainting` 适配器**：支持局部重绘（需 mask 生成逻辑），对"只改鼻子"类需求更精准
2. **新增传统 CV 适配器**（如腾讯云人脸美型）：对"瘦脸"等纯形变项目做 fast path（<1秒、0.005元/次）
3. **动态 strength 参数**：让用户通过滑块控制"调整幅度"，传入 `AiEditInput.strength`
4. **混元备用适配器**：实现真实调用，作为 primary 失败时的 secondary fallback
